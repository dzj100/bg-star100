# 煞有其时 (that_time_you_killed_me) 桌游助手 — 规格说明

> v0.4 · 规则已核对 + 补充修订（2026-09-04）· 状态：实现中
> 修订 ①「仅 1 次行动」的棋子可选、执行后可手动【结束行动】；② 三板块布局手机竖排优先、宽屏横排
> 修订 ③（2026-09-04）可选「生长」模组：开局弹窗勾选，种子/灌木/大树/拨除（详见 §13），基础模式行为不变

> v1 范围：本地双人（面对面传机）+ 人机对战；后续可接 `online-boilerplate` 做 2 人联机

## 1. 组件清单

| 组件 | 数量 | 说明 |
|------|------|------|
| 时空板块 | ×3 | 分别命名「过去」「现在」「未来」，各 4×4=16 格 |

## 2. 版面与坐标

- 逻辑顺序固定：**过去 | 现在 | 未来**，只有相邻板块互通（过去与未来不相邻，不能直穿）。**布局：手机竖屏三板块上下堆叠（过去→现在→未来），宽屏/桌面横向排一行**（Q6 已确认方向）。
- 每板块内部编号 1~16，**行主序**：第 1 行 1–4，第 4 行 13–16；1 号=左上角，16 号=右下角。（由原文"1号格/16号格"及例 2 的 1→5→9 纵向推挤推断，视觉层待定）
- 方向对应：上 −4 / 下 +4 / 左 −1 / 右 +1；**边界（墙）**：顶行(1-4)不可上、底行(13-16)不可下、左列(1,5,9,13)不可左、右列(4,8,12,16)不可右。
- 跨时空对应格编号相同：某子在"未来 6 号格"，穿越后落在"现在 6 号格"。

## 3. 开局（2026-09-04 修订：白 1 号格/黑 16 号格，焦点对调）

1. 白方：在 3 个板块的 **1 号格**各放 1 枚白子（盘上 3 枚）。
2. 黑方：在 3 个板块的 **16 号格**各放 1 枚黑子（盘上 3 枚）。
3. 焦点：白焦点 →「过去」；黑焦点 →「未来」（与各自 1 号格 / 16 号格的家对应——白家在左上角落且从过去出发，黑家在右下角落且从未来出发）。
4. **随机决定先后手**；先后手与颜色无关。
5. **人机对局随机分色**：AI 模式开局随机给玩家分配黑/白（各 1/2），程序执掌另一色；先后手同样随机（2026-09-04 新增，原为"玩家恒执黑且黑方先行"）。双人同屏模式颜色固定：黑=玩家 1、白=玩家 2。
6. 死亡棋子永久出局，不回收；备用子一旦当作分身放下即成为普通棋子（Q1 已确认：分身耗尽不可再生，双方总数恒 ≤7）。
7. 新局默认写入一条开局日志：`对局开始，黑方/白方先手`（回合 1、归属先手方），出现在提示条与日志抽屉首行。

## 4. 回合流程（当前玩家 P）

1. **选子**：P 只能在自己焦点所在时空内选择 1 枚己方棋子；该子须**至少有 1 次合法行动**才可选；若焦点时空无己子 / 所有己子都无任何合法行动，按 §6「卡死处理」空过（Q3 已确认）。
2. **行动**：选定棋子执行 **2 次行动**（同一棋子连续执行；移动/穿越可重复选、顺序任意）。**补充修订（2026-09-03）**：只有 1 次行动可选的棋子同样可被选中；执行 1 次行动后若已无任何合法行动，可手动【结束行动】提前结束；若仍有第 2 次合法行动则必须执行。
3. **收尾**：P 必须把自己的焦点移到**另一时空**（不允许留在原时空）。
4. **行动结束即判胜负**：完整行动（2 次行动 / 提前结束 / 空过）结束后立即检查一次；双方同时满足负条件判平局（Q4 已确认，见 §7）。
5. 交换回合给对方。

## 5. 行动细则

### 5.1 移动

- 沿上/下/左/右移动 1 格；禁止斜向；禁止越墙（§2 边界）。
- **非法**：目标格是己方棋子（不能主动与自己的棋子会面）。
- 目标格为空 → 直接进入。
- 目标格是对方棋子 → 触发推挤（§5.2）。

### 5.2 推挤

- 目标格被占时，从目标格起沿移动方向**连续被占**的格子构成推链 C1..Ck（遇空格或墙为止，不连续则不推）。
- 推链整体沿移动方向推进 1 格：Ci → C(i+1)，移动者 → C1。
- **撞墙**：推链最前端 Ck 的下一个位置是墙（出界）→ Ck 上的棋子死亡/出局；其余棋子继续就位。
- 推链**不分敌我**：己方棋子也可能被推进、被撞死（允许，属战术）。
- **悖论（同色相遇）**：推链中若存在相邻同色两子（后子将踏入前子原位）→ 该相邻同色对**全部死亡**，即使前子身后有空位可进（原文例 2 语义）；相邻同色段 >2 时按相邻对两两结算，该段整段死亡。
- 结算顺序（假定 Q5）：先结算死亡（撞墙 + 悖论），幸存者整体推进，移动者落在 C1；同色段死亡后，其身后更深的剩余链仍整体推进。

### 5.3 穿越（时空穿越）

- 将棋子移入**相邻时空**中**同编号**的格子（过去↔现在、现在↔未来）。
- **非法**：目标同编号格上存在**任何一方**棋子（穿越不触发推挤）。
- **逆时穿越**（未来→现在、现在→过去）：在**出发格**留下 1 枚分身 —— 消耗 1 枚备用子放在原格；备用耗尽则这两个方向的穿越不可执行。
- **顺时穿越**（过去→现在、现在→未来）：不留分身。
- 分身视同普通棋子：可被选择、移动、推死、继续穿越。

### 5.4 两次行动的组合

任意组合、顺序任意，例如：移动+移动（共走 2 格、可两次推挤）；移动+穿越（先走再穿，或先穿再走）；穿越+穿越（未来→现在→过去，逆时两次各留 1 分身；或过去→现在→未来顺时两次无分身）。

### 5.5 提前结束（结束行动）

- 触发条件：棋子完成 1 次行动后已无任何合法行动（含开局选子时仅有 1 次行动可选的情形）。
- 玩家点【结束行动】进入移焦点阶段（§4 步骤 3）；有第 2 次合法行动时按钮不可用，必须执行完 2 次。

## 6. 焦点

- 双方各有自己的焦点，标记"本回合能操作哪个时空"。
- 回合内只能操作焦点时空中的己子；其它时空的己子本回合不可操作。
- 回合结束时，焦点**必须**移到另一时空（另外 2 个时空任选）。
- 两个焦点可同时指向同一时空，互不冲突。
- **卡死处理（Q3 已确认）**：回合开始时若焦点时空没有己方棋子、或该时空所有己子都**无任何合法行动** → 本回合**空过**：跳过行动，仅把焦点移到另一时空，然后交换回合。空过不是判负条件。

## 7. 胜负（Q4 已确认 + 2026-09 修订）

- 一名玩家在 ≥2 个时空内没有任何己方棋子（分身也算）→ 该玩家**判负**，对手获胜。
- 只数盘上棋子；备用未上盘不计。
- **判定时机：行动结束即判** —— 当前玩家第 2 次行动结束（或【提前结束行动】/ 空过）后立即检查一次；未终局才进入「移焦点」。移焦点时兜底复查一次（兼容旧存档）。（2026-09-03 修订：原为"回合末即移焦点后判定"，现提前至行动结束。）
- **平局**：判定瞬间若**双方同时**满足负条件 → **平局**，无人获胜；不再按"行动方优先"裁决。（修订后判定点前移，双方同时崩盘的可能性随之提高，如推链中己方与对方同归于尽。）
- 检查顺序：先查双方是否同时满足（→ 平局）；再查**对手**（满足 → 当前玩家胜）；再查**当前玩家自己**（满足 → 对手胜）；均不满足则游戏继续。

## 8. 规则示例（理解校验）

### 示例 1（原文：推挤撞墙，己子可误杀）
某时空初始：1=黑，2=白，3=黑。黑方回合选 3 号黑子：
1. 左移 → 目标 2 有白子，推链 [2白, 1黑]，1 号黑撞墙死亡；结果 1=白，2=黑（原 3 号），死亡黑×1。
2. 同子再左移 → 目标 1 有白子，推链 [1白]，白撞墙死亡；结果 1=黑，死亡白×1。
✓ 与原文一致（己方黑子被自己误杀 + 连续推动）。

### 示例 2（原文：悖论）
某时空初始：1=黑，5=白，9=白。黑方回合选 1 号黑子下移 → 目标 5 有白子，推链 [5白, 9白] 相邻同色 → 悖论，两白皆死（9 号后本可进 13 空格，仍死）；黑 1→5。✓ 与原文一致。

### 示例 3（原文：双穿越 + 分身）
白子位于未来 6 号格（备用 4 枚）：
1. 穿越 未来→现在：现在 6 空 → 白子到现在的 6；未来 6 留白分身（备用→3）。
2. 穿越 现在→过去：过去 6 空 → 白子到过去的 6；现在 6 留白分身（备用→2）。
✓ 白子在 3 个时空同编号格各 1 枚，对应原文"从未来到现在到过去"。

## 10. 逻辑状态结构草案（与 UI 解耦）

```js
S = {                                 // 实际实现见 game.js（newGame 返回）
  mode: 'local2p' | 'ai',             // 开局模式（AI 分色 aiSide 由 UI 层另存，见下）
  first: 0 | 1,                       // 先后手（0=黑 1=白；local2p 同样随机）
  turn: 0 | 1,                        // 当前行动方
  turnNo: 1,
  focus: [2, 0],                      // [黑焦点时空, 白焦点时空] 0过去 1现在 2未来
  boards: [                           // 3 个时空 × 16 格（行主序）
    {                                 // 每时空：cell 为基础棋盘层，恒存在

      // 生长模组开启时另附两层（由 hydrate 补齐，基础模式引擎不读写）：
      //   pl: [null | {k:'bush'} | {k:'tree',down:0|1} ×16]  植物层
      //   sd: [0 | 1 ×16]                                    种子层
    },
    { cell: [...] },                  // 现在
    { cell: [...] },                  // 未来
  ],
  spares: [4, 4],                     // 双方备用分身余量（盘上子 + 备用 + 死亡 = 7）
  dead: [0, 0],
  stage: 'select' | 'act' | 'focus' | 'over',
  sel: null | { era, i },             // 当前选中的己子及其时空
  acted: 0 | 1 | 2,                   // 该子已完成行动数（<2 时若已无合法行动可手动结束）
  over: null | { winner: 0 | 1 } | { draw: true },   // 终局（平局见 Q7）
  log: [ { no: 1, p: 0|1, text: '…' } ],  // 事件日志（回合/行动方/纯叙事），上限 60 条
  // —— 生长模组（S.mods 含 'growth' 时启用；规则逻辑在 mods/growth.js）——
  mods: ['growth'] | [],              // 本局启用的模组 id 列表（空 = 经典规则）
```

- 开局常量（2026-09-04 修订）：`boards[e].cell[0] = {c:1}`（白方 1 号格）、`boards[e].cell[15] = {c:0}`（黑方 16 号格）、`focus = [2, 0]`（黑焦点=未来、白焦点=过去）。其余如上。
- AI 分色不在 S 内：UI 层保存 `aiSide`（0=AI 执黑/1=AI 执白），随存档持久化；旧档缺省 `1`（AI 白方）。

- 逻辑层建议独立成纯函数（合法行动枚举 / 推挤结算 / 胜负判定），便于人机 AI 与单测复用。

## 11. 存档续玩（已实现）

- key：`that_time_you_killed_me-state`；值 `{v:2, mode:'ai'|'local2p', aiSide:0|1, S}`，S 即 §10 引擎局面（含事件日志与 mods，重载后记录抽屉/模组不丢）；`aiSide` 仅在 AI 模式有意义（2026-09-04 新增：AI 分色随机），旧档缺省按 1（AI 白方）。
- **版本与迁移（2026-09-04 新增 v2）**：v1 旧档（无 `mods` 字段）读取时迁移为 `mods: []`（经典规则），校验通过后照常恢复，下次写入自动升 v2；v2 存档校验 `mods` 为已知模组 id 字符串数组，growth 开启时深度校验 `pl`/`sd`（各 16 位）、`seeds ∈ [0,5]`，任一不过即清档回封面。
- 写入时机：开局即存；每次引擎状态变更后立即落盘——演出较长的移动/穿越在引擎结算后、动画播放前先存，中途关页不丢步；AI 分步执行每步落盘。生长模组开启时 UI 另存 `activeMods`（= `S.mods`），重开/再来一局沿用不弹窗。
- 恢复：页面加载（DOMContentLoaded）若有存档 → 自动进对局界面（跳过封面）并重建棋盘/提示条/面板/日志。AI 回合进行中恢复会自动续跑（含 act 中途断点：aiPlan 从当前已选子收尾排剩余行动），人类回合恢复后可继续操作；终局画面同样保留。
- 清档：点【菜单】/【返回菜单】= 放弃本局并清除存档，下次打开回封面。
- 容错：存档 JSON 损坏或结构校验不过（版本/棋盘/阶段/回合字段不符）→ 静默清档回封面，不阻塞启动。

## 12. UI/交互草案（规则核对后再细化）

- 视觉主题取原版桌游封面灵感：**米白底 + 橙/青/绿/粉/黑扁平几何风**（区别于合集内其它深色游戏）；动画演出走 game-feel：移动推挤命中反馈、悖论/撞墙死亡演出、分身出现、焦点脉冲、屏幕震动、胜负结算动效。
- 三板块布局：手机竖屏竖排 / 宽屏横排，JS 按视口算格子尺寸；选中高亮、合法落点提示、穿越目标按钮（含"分身"标记）、行动计数与【结束行动】按钮、空过提示、焦点指示、回合横幅、胜负结算面板。
- 分身余量（备用分身黑×N/白×N）：宽屏以顶栏角标显示；窄屏（`≤560px`）顶栏无空位，改为**右侧悬浮小窗**（fixed，底部向上 1/5 处，竖排三行 分身/黑×N/白×N；`pointer-events:none` 纯展示不挡点选；实测坐落在棋盘右侧留白、不遮格），穿越/阵亡后随渲染实时刷新。
- 焦点选择：面板恒显 过去/现在/未来 三个按钮，当前焦点时空的按钮置灰 disabled（显示"当前 · XX"），其余两个为可选目标；演出（busy）期间的点击不丢弃，收尾按最新局面重放，非法则静默丢弃。
- 人机难度（aiPlan 启发式，两个"反浪费"约束）：
  - **折返惩罚**：候选按"两动后布子与回合初逐格完全相同"判定净零折返（先左再右空耗 2 行动），罚 12 分——压过 ±3 抖动噪声打破平局，但轻于子力差 26 分，AI 在"唯一出路是自损子力"时仍会选择空耗折返而非送子。
  - **焦点机动性**：焦点落点按"下回合出发点"评估——落在己方无子时空下回合必空过，重罚；有己子时空按机动性（己子数 + 合法行动数）加分，不再由随机噪声决定焦点。

## 13. 生长模组（可选 · 2026-09-04 新增）

桌面《煞有其时》官方扩展。开局在**模组选择弹窗**勾选「生长」（默认不勾）；不勾选 = 经典规则，引擎行为逐字节不变。
**架构约束：game.js 只留注册/dispatch 点，整套规则独立在 `mods/growth.js`**（`G.regMod` 注册，`hookOf(S,name)` 按 `S.mods` 分发 legalActions/applyAction/evalState/sameLayout/hydrate），后续新模组照此一个模组一个文件。
以下规则均已与用户确认（2026-09-04）。本节约定：格号使用**玩家视角 1~16**；引擎/测试为 0 基（i=格号−1），示例表按需标注。

### 13.1 公共种子与植物层

- **种子 ×5 = 公共池、无归属**：任一方可播己子所在格或 4 邻格内的种子，也可拨除任何种子并回收。池守恒：`盘上种子数 + 池余量 ≡ 5`。
- 格可同时含 棋子+种子（互不排斥）；**种子透明**：可走入/被推链穿过/作为穿越落点/被倒树盖住（树盖种：渲染隐藏、拨除仍可回收）。
- 植物层与棋子层分离：植物占格（不可走入、不可推入、不可穿越落点），但**棋子可与种子同格**。种子与植物互斥仅由 播种/生长 校验维护——**树倒落点若已有种子则压盖其上**（种子保留、渲染隐藏、可拨除回收），此时种子与植物同格是被允许的例外。
- 植物仅两类：**灌木丛 bush**（不可动墙体）与**大树 tree**（站立足 `down:0`；倒下 `down:1` = 卧倒原木，墙体语义，并记**原生长列 `o`** 供拨除追消）。**树与灌木外观区分、站树与倒树形态区分**（UI §13.8）。

### 13.2 播种（sow）与生长（朝未来即时结算）

- 范围：**己子所在格 + 上下左右 4 邻**（对己方棋子站着的格可直接播）。
- 非法：目标格有 对手棋子 / 种子 / 任何植物。
- 消耗 1 粒公共种子（池空不可播）；播下后棋子不动，占 1 次行动。
- **生长在播种瞬间朝未来判定，只判一次、不补长**：`seed@过去/现在` → 若 (E+1, 同号格) 完全为空（无棋/无种/无植物）→ 长出**灌木丛**；灌木丛长出同时，若 (E+2, 同号格) 完全为空 → 长出**大树**。任一级不满足则只长到满足处（或原地只留种子）。
- 播种在「未来」(E=2) 合法：种子落下即停（无下一时空），以后随时可被拨除回收。
- 种子不会自行再长：生长仅由播种瞬间触发，拨除/清空不复活植物。

### 13.3 拨除（pluck）

- 范围同播种；目标格须有种子（含被倒树盖住的、站有己方棋子的）。
- 效果：种子回收入池（+1）；**只消本种子长出的植物**——同号格 (E+1,i) 的灌木（该位灌木唯本种子来源）、(E+2,i) 的立树（唯本种子来源），以及**被推倒后已离开原列的大树**（沿推力方向恰 1 格，上下左右皆可；倒树状态记原生长列 `o` = `{k:'tree',down:1,o:列号}`，拨除时在原列四方向邻格循 `o` 追消）。**槽位若落着别家来源的植物（如自家树被推走后、别家树倒进 (E+2,i) 空槽；或该槽位本身是别家灌木）一律不动**——不会误消别家树木。
- 拨除占 1 次行动，棋子不位移。

### 13.4 树木与推挤（墙体/多米诺/压垮/挤死）

- **灌木丛与倒树 = 不可动墙体**：直推目标为它们 → 非法；推链前端撞上 → 前端棋子撞墙出局（同基础规则）。
- **立树可被推倒**（移动者直推与推链推倒皆可，见 E3/E5）：
  1. 沿推力方向取**连续立树段 run**；
  2. run 末端下一格 = 空/种子 → 树段多米诺前移 1 格（每棵倒下 `down:1`），树段原格腾空，**移动者（或链前端棋子）落第一棵树的原格**；
  3. run 末端下一格 = 棋子 → 树段前移并**压垮落点棋子**（`crush` 压垮出局，**含己方**；该格最终是倒树）；落点种子被盖住保留；被压垮棋子后方的棋子不受影响；
  4. run 末端下一格 = 灌木/倒树/墙 → 树段纹丝不动，**该方向不构成合法行动**（直推禁止；推链顶树时见 E5 挤死）。
- **悖论优先**：推链若含相邻同色（悖论全员死亡）→ 结算退化为基础规则推进，树不参与、不倒下。
- **树倒下 = 动作主体是树**：树不进入棋子推链；棋链幸存成员整体前移（基础规则），移动者落树段让出的原格。
- **倒树不可再推倒**，对其后一切判定等同灌木丛（墙体）。

### 13.5 官方示例 E1–E5（0 基 → 玩家号 = 0 基 +1；→ 表示推力方向）

| 案例 | 摆景 | 结算 | 要点 |
|------|------|------|------|
| E1 直推撞单树 | 黑@2号（i1）、立树@3号（i2）、白@4号（i3） | 黑右移合法；树倒 3号→4号格 **压垮白**（白出局）；黑落 **3号格（树原格）** | 官方案例原文「玩家2的棋子移动到3号格」**经确认是笔误**：落树原格的是移动者 |

### 13.6 与经典规则的差异清单（模组开启时生效）

1. 非法推倒/进入植物格一律不进 legalActions（人类与 AI 同源，拿不到非法选项）。
2. 死亡因由新增两类：`crush` 压垮（被倒树压中）、`squash` 挤死（树被顶住时被夹死）；两者叙事/演出与撞墙、悖论并列。
3. 胜负判定不变：死因无关紧要，仍按「≥2 时空无己子」立即判（行动结束即判）。
4. 空过判定覆盖模组行动：子仅播种/拨除可选也可正常选子执行。

### 13.7 AI / 净零与存档（实现注记）

- `evalState`（仅 growth 开启加权）：灌木 +2、立树 +5、倒树 +3（远小于子力差 26）；种子按所在格 −2（无生长位）/ +1（可生长位）。
- `sameLayout` 比较各板 pl（k + down + 倒树原列 o）与 sd——AI 净零折返判定把「播+拨」同格回收视为原地踏步。
- 数据层：`hydrate` 保证 pl/sd 16 位数组存在、种子池守恒重算（`seeds = 5 − Σsd`）。
- 存档 v2（见 §11）：`mods` 数组持久化，v1 旧档迁移为经典规则；恢复后 UI `activeMods` 跟随 `S.mods`。

### 13.8 UI/交互（2026-09-04 已实现）

- **模组选择弹窗**：菜单点【人机对战/双人对战】→ 弹层列出模组复选框（带名称/说明；生长默认不勾）+【开始游戏】【取消】；无模组则不弹直接开局。重开/再来一局沿用本局模组、不再弹窗。

- **目标格提示**：移动模式画方向/穿越箭头；播种/拨除模式在合法格打标签「播种」「拨除」（仿穿越提示下缘小签样式，绿色区分）。
