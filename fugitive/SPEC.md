# 神探缉凶 (Fugitive) 人机对战系统 — SPEC

单人手机页游：玩家自选身份（大盗 / 警探 / 随机），系统 AI 扮演另一方，进行完整对决。
**规则以用户实体第一版（繁中）规则书为准**（2026-08-31 用户补充确认 + 4 项裁决确认）。

> 术语：用户规则书称「大盗 / 警探」（本实现 UI 即用此术语）。旧版 UI 曾用「潜逃者 / 缉凶者」，已废弃。

## 一、规则（已确认版）

### 组件
- 43 张地点牌，编号 0–42
- 每张地点牌（1–41）自带**掩护标记**：奇数牌 1 个、偶数牌 2 个；**0 与 42 无掩护标记且不能作为掩护牌**
- 无独立 Alibi 卡（旧实现的 3 张不在场证明作废）

### 设置
1. 桌面中央两个区域：**出牌区**（单独一行，初始正面朝上放置 0）+ **摸牌区**（三个牌堆，各自洗混、面朝下）：
   - A 堆：4–14（11 张）
   - B 堆：15–28（14 张）
   - C 堆：29–41（13 张）
2. 将 1、2、3、42 发给大盗，大盗再从 A 抽 3 张、B 抽 2 张 → 累计 9 张手牌
3. 警探手牌 0 张
4. 大盗开始第一回合，随后警探，之后交替进行

**对局模式（普通 / 🎩 怪盗，2026-09-06）**
- 开赛前可选（人机对战：登录页模式开关；联机对战：房主等候室「对局模式」卡片选择，随身份配置原子落库）
- **普通**：按上述标准设置（大盗 9 张）
- **怪盗**：大盗初始手牌 **12 张**——在普通 9 张基础上，A、B、C 牌堆**各再多摸 1 张**（合计 A 抽 4 张、B 抽 3 张、C 抽 1 张；三堆余量相应变为 A 7 / B 11 / C 12）
- 模式作用于**本局的大盗方**（人机对战中无论玩家或 AI 扮演大盗、联机中无论房主或成员扮演大盗），其余回合流程、约束与胜负条件完全不变

### 回合流程

**第一回合**
- 大盗：打出 **1 或 2 张**地点牌（均面朝下）。第一张只能是 1/2/3；每张须递增，且点数不能大于出牌区最后一张 +3（可追加掩护牌放宽）
- 警探：从任意牌堆抽取，累计抽 2 张；然后**必须**猜测 1 个或多个数字

**后续回合**
- 大盗：1. 从任意牌堆抽 1 张；2. 可选是否面朝下打出 1 张地点牌（**可以选择不出牌**）
- 警探：从任意牌堆抽 1 张；然后**必须**猜测 1 个或多个数字（无跳过）
- 三堆全空时跳过摸牌阶段：回合交接 `needDraw = anyPileLeft()`；警探首回合第二张同样检查（摸完最后一张即不再要求）；即使出现残留 `needDraw`（如旧存档），点网格时会自动清除并放行，**任何情况下不再弹「先进行摸牌」**

### 打出地点牌与掩护
- 地点牌必须比出牌区最后一张更大，且点数 ≤ 最后一张 + 3 + Σ（本次所用掩护牌的掩护标记）
- 打出地点牌时可追加任意数量**掩护牌**（数量无上限）：掩护牌也面朝下打出，**不须递增**，警探能看到打出了几张（但看不到数字）
- 掩护标记数 = 奇数牌 1 个、偶数牌 2 个；0、42 不能作掩护牌
- 例：出牌区到 10，选 5(1) + 7(1) + 8(2) 作掩护 → 标记合计 4 → 上限 = 10+3+4 = 17，可打出 11~17 任意数字
- 主牌被猜中翻开时，其掩护牌一并翻开
- **42 同样受约束**：须满足 ≤ 上一张 + 3 + Σ掩护标记（裁决 #4）；打出时 42 直接面朝上

### 猜测（裁决 #1 / #2 已确认）
- **可猜任意 1~41 的数字**，不要求手牌中有，猜牌**不消耗、不打出**（裁决：警探手牌非消耗品，其作用仅为排除可能性、压缩大盗逃跑路线——手牌数字不可能在暗牌中，因为牌唯一）
- 单猜：命中某暗置地点牌 → 翻开该牌**及其掩护牌**；未命中 → 地点牌无事发生。**猜过未中的数字不置灰、可再猜**（大盗日后可能摸到并打出，仅计入「猜错次数」统计）
- 多猜：所有数字均为暗置地点牌 → 全部翻开（掩护牌也翻开）；**任一数字不存在 → 一张都不翻开**，且无法确定哪个错（不新增统计）
- **已公开数字（翻开的藏身处 / 掩护牌）不可再猜**（裁决 #2）
- 掩护牌不可作为猜测目标
- **警探每个回合必须猜测**（裁决 #3）；猜错无任何代价 → 多猜的"全中才翻"是唯一风险点

### 搜捕（打出 42 时结算）
- 大盗打出 42 号牌 → 42 **直接面朝上**打出
- 若此时已翻开的地点牌（**不含掩护牌**）中数字**均不大于 29**（没有翻到 30 及以上）→ 警探进入**搜捕**阶段：警探**必须从小到大依次单猜**仍面朝下的地点牌；猜非最小暗牌视为跳过，立即失败。只有在**所有**面朝下的地点牌都猜对时警探获胜，**猜错即大盗胜**（手牌无消耗，不存在手牌耗尽）；**猜错同样先弹气泡对话（警探「我猜地点有 X」→ 大盗「你猜错了」）再结算大盗胜**。若已翻开过 **30 及以上** → 大盗**直接逃脱获胜**，不进入搜捕
- 搜捕提示语：告知警探「必须从小到大依次猜」
- 结算页：未被猜到的地点牌以「？」展示（**有掩护的暗置牌同时显示「掩护×N」徽标**，与对局中一致；掩护牌面朝下只露数量，点击可复盘查看真实数字与掩护牌具体数字）

### 胜负
- 大盗胜：打出 42 且不触发搜捕，或搜捕中警探猜错
- 警探胜：翻开大盗全部地点牌，或搜捕中全部猜对

## 三、数据结构（已确认）

```js
state = {
  v: 2,  // 结构版本（旧缓存不兼容，丢弃）
  mode: 'normal' | 'phantom',  // 对局模式：普通 / 怪盗（v2 旧存档缺该字段，load() 迁移默认 'normal'）
  phase: 'landing' | 'pick-role' | 'playing' | 'manhunt' | 'over',
  humanRole: 'fugitive' | 'marshal',
  piles: { A: [num...], B: [num...], C: [num...] },  // 顶牌在尾部
  fug: {
    hand: [num...],
    route: [{ num, hidden, cover: [num...] }...],  // cover = 掩护牌数字（暗置，随主牌翻开）
  },
  mar: { hand: [...], firstDraw: bool, drawCount: 0, marks: {} },  // marks: { n:1 } 玩家手动「怀疑」标记
  marMissed: [num...],  // 猜错记录（仅结算页「猜错次数」统计，不置灰、不影响可猜性）：单猜/搜捕致命猜错记实际数字，多猜整组未中记 0 占位
  turn: 'fugitive' | 'marshal',
  firstTurn: bool,   // 大盗首回合（放 1~2 张）
  needDraw: bool,
  log: [{ t: 毫秒时间戳, msg: HTML, cls: 颜色类 }...],  // 上限 80 条
  turns: 1,
  winner: null | 'fugitive' | 'marshal',
}
```

- `marks(n)`：奇数 → 1，偶数 → 2；0、42 不可作掩护牌
- 放置校验：`num > last` 且 `num ≤ last + 3 + Σ marks(cover)`
- 翻开：主牌与 cover 一并 `hidden = false`
- 搜捕判定：`max(已翻开主牌 num) ≤ 29`（不含 cover；翻到 ≥30 直接逃脱）；42 打出时 `hidden = false`
- 警探可猜集合（UI 置灰不可选）= 已公开数字 ∪ 警探手牌（猜过未中的数字**不**置灰，可再猜）
- 猜测不修改手牌；「猜错次数」统计口径 = **每次失败的猜测动作**：单猜未中与搜捕致命猜错（顺序/数字错误）记实际数字，多猜整组未中记 0 占位（无法归因具体错误项，但该动作本身计 1 次）
- 发牌：`newGame(humanRole, mode)`——mode 缺省 `'normal'`；怪盗（`'phantom'`）时大盗手牌 = `[1,2,3,42]` + A×4 + B×3 + C×1（共 12 张），三堆余量 A 7 / B 11 / C 12；手牌存放顺序同普通（固定 4 张在前），展示时仍按数字升序
- `mode` 旧存档迁移：load() 检测缺失时补 `'normal'`（v2 存档升级）；「再来一局」与联机「再来一局」沿用本局 `mode`
- `mar.marks` 旧存档迁移：load() 检测缺失时补 `{}`（v2 存档升级）

## 五、AI 设计

### AI 警探（玩家当大盗）
- 已知排除集 = 已公开数字 ∪ 警探手牌（猜过未中的不排除——大盗日后可能打出）
- **AI 内部排除集（按槽龄过滤，2026-09-07，替代旧「全量排除」）**：`aiMarMissed` 记猜过未中的数字，`aiMarMissLen` 平行记录各次猜错时的大盗路线长度——猜错只证明「当时已放置」的槽不含该数，**排除仅对 missLen > 槽序号的旧槽生效，之后新放的槽仍可能是该数**（大盗日后补打；旧版把猜错当永久排除，会把补打真值从窗口里永久剔除，系统性漏猜）；防死循环仍有效（旧槽窗口随猜错单调收窄）；对玩家 UI 不置灰、玩家仍可再猜
- 对每个暗置位置枚举候选：满足递增 + 相邻差 ≤3 约束，且不在该槽的排除集内；公开位置用实际数字作前驱；**断链兜底范围约束为「最后公开牌 +1 ~ 41」**（路线严格递增，候选绝不含 ≤ 最后公开牌的数字——避免断链时盲猜 1）
- **窗口封顶（2026-09-07）**：暗格必小于其后任一公开锚点 → 反向预计算每槽上限 cap[i] = 下一公开锚点 − 1（无后续公开则为 41），窗口枚举与兜底范围均不越过该值——不把猜测浪费在必然不可能命中的「锚点之后」数字上
- **掩护感知窗口（2026-09-07，替代旧「忽略掩护放宽」的天然弱点）**：暗格桌面可见掩护张数 N（值不可见，每张 1~2 标记取最大）→ 该格窗口上限放宽为 prev+3+2N，绝不漏真值；**无掩护（N=0）暗格保持严格 +3 精确性**。信息与人类警探完全相同（掩护张数桌面可见、值翻牌后才见）；窗口放宽后 AI 从最低位逐发探测，命中即翻牌重锚，链不再漂移。垫牌/虚张（有掩护但落在低位段）仍能拖慢探测 2~3 发，骗术互制成立
- 决策（每回合必猜）：
  - **批量唯一窗口（2026-09-07）**：存在 ≥2 个唯一候选位置 → 一次全猜（每个数字都被公开锚点钉死，整批必中、无猜错风险）——单回合多翻牌直接提速「翻全」竞赛，是平衡最大单项；恰 1 个唯一候选 → 猜该数字（85%）或随机一个唯一候选（15%）
  - 无唯一候选 → **命中概率加权（2026-09-07，替代旧「槽数同频」）**：候选跨槽按 1/窗口大小 求和，猜总权值最大者——窗小者单槽命中率更高，槽数同频不代表同概率；平局取小者、15% 随机防模式化
  - 候选全空 → 随机猜一个未排除数字（兜底）；全部数字已猜过 → 从已猜未中随机盲选
- 抽牌选堆（威胁优先）：统计所有暗置位置的候选数字在各堆（A/B/C）的出现次数，**摸候选最密集的堆**（摸走 = 大盗打不出，压缩路线）；平局按 C → B → A；所有堆都无候选（如首张暗牌候选 1~3 不在任何堆）→ 从大到小 C → B → A；掩护感知窗口使跳张目标（多落在 B/C 堆）自动计入威胁
- 搜捕：**必须从小到大依次猜**——用推断推导第一个暗置位置（= 当前最小暗牌）的候选集，猜其中最小候选（唯一候选即准确推断），猜错即败；**不读取暗置牌真实数字**（公平，与玩家同信息）
- **AI 对 AI 平衡（2026-09-07，sim-balance.js 无头模拟、同种子 6000 局对照）**：四项升级合计警探胜率 **33.4% → 41.7%**（直逃42 53.9%→46.6%、翻全胜 31.2%→39.7%）；单项拆解：命中概率加权 +1.7pp、窗口封顶 +0.5pp、猜错按槽龄 +0.4pp、批量唯一窗口 +6.1pp（主杠杆，各单项近似可加）。曾试「低区优先」（命中相近时先翻 ≤29，把必败的武装直逃局推迟成搜捕局）实测净负未采纳——翻全竞赛的命中速度比「武装直逃」时机更值钱；曾试「锚点优先」（无唯一时死探最前暗格）严重恶化（33.5%→18.9%，把对局拖进搜捕再输）未采纳

### AI 大盗（玩家当警探）
- 普通移动（差 ∈ [1,3]，拟人加戏 2026-09-07）：**效率跳跃**先试——50% 概率评估距 last+5~+7 的提前跳（need 2~4 标记，≤2 张「恰好凑满」的最小代价组合，见 coverFit2，跳最大可行者），**开局首张除外**（route 为空：警探推理以起点 0 起步只认 1~3，首张跳 5~7 会永久甩开其锚点，第二张起才允许）；跳不成/未触发 → **顶格小步** 60%（打范围最大张，垫「被跳过」的牌：60% 垫 1 张、跳过 ≥2 再 40% 垫第 2 张——被跳过牌打完即成死牌，零活牌浪费，且补上老死牌虚张「last=0 无死牌」的首手盲区，开局也能制造「掩护=跳远」假象）；40% 保持原中位随机裸打防模式化
- 跳跃：主牌 v（差 >3）需要 `need = v - last - 3` 个掩护标记 → 从手牌（排除 42）贪心收集**最小牌**凑标记（小牌作掩护不浪费大牌）
- 42 冲刺策略（2026-09-07）：42 在手且能一步打出时——
  - **公开地点牌 >29（打出即直接获胜）**：无条件冲，掩护代价不限（梭哈也无妨）；
  - **将触发搜捕（公开 ≤29，冲 42 ≠ 稳赢）且掩护凑齐后手牌仍剩 ≥2 张**：冲，并按「搜捕虚张」押死牌；
  - **将触发搜捕且掩护近乎整手梭哈（打出后剩 ≤1 张）**：不冲，延迟——落入常规小步（**延迟状态禁一切加戏**：顶格垫/效率跳跃/老死牌虚张全关，裸打——每 1 标记都是下回合冲刺弹药）/ 小跳（必要掩护照常）/ pass，每回合重新评估（42 为固定手牌永不打丢、last 单调增使 need=42-last-3 单调减，延迟只会让冲刺更便宜，绝不卡死）
- **搜捕虚张（2026-09-07）**：冲 42 将触发搜捕时，在必需掩护外再押死牌——剩余死牌（≤last 未被掩护占用）≥2 时 50% 概率 +1 张、≥3 时再 50% 概率 +第 2 张（上限 2 张 / ≤4 标记）；打破警探「42 掩护标记 ⇒ 反推 last=39-T」的精确推断；死牌本不在警探候选内，翻开排除价值 ≈0
- 首回合：放 1 张后若有合法第二张则补放，否则结束回合
- **虚张掩护抖动（2026-09-06）**：普通移动（差 1~3，本可裸打）有 **35%** 概率强行挂掩护，伪造「跳远」迹象，让警探「有掩护=跳远」的推断不可靠；只消耗**死牌**（≤ 上一张、永不能再当主牌的牌）且至少留 1 张兜底，绝不挪用推进牌——死牌 ≥2 才可抖 1 标记、≥4 时另有 50% 升级 2 标记（凑不够即放弃）；2026-09-07 起位于加戏分层末位：效率跳跃/顶格垫命中时该回合不再叠加抖动，仅「中位随机裸打」路径触发
- **加戏与 42 弹药的边界（2026-09-07，收窄旧「42 在手一律禁」）**：顶格垫/效率跳跃/老死牌虚张共用手牌标记预算，只发生在 42 分支让位之后——**42 在手但当前凑不齐掩护**（need > 手牌可凑标记，冲刺不可行）时允许加戏，不浪费骗术机会；**仅「42 可冲但被梭哈规则延迟」状态禁一切加戏**，裸打推进、标记留给下回合冲刺。coverFit2 = 效率跳跃专用垫牌选择（区别于 pickCovers 最小张贪心）：≤2 张内凑满 need，代价排序 活牌数（>main 打完仍是主牌候选，优先不用）→ 张数 → 浪费标记 → 牌面小者
- 抽牌选堆（权重优先，与警探威胁优先对称）：以路线当前位置 last 为基准，给每堆剩余牌打分——last+1~last+3 立即可打 3 分、last+4~last+8 需少量掩护 2 分、更远 1 分、≤last 只配当掩护 0 分——**摸总分最高的堆**，平局按 C → B → A；**兜底**：无可推进牌（路线近 42）或首选堆已空 → 从大到小摸任意非空堆（否则手牌只剩 42 时会永远摸空堆）；三堆全空记录「牌堆已空，大盗无法摸牌」并跳过摸牌，回合照常推进
- 怪盗模式（2026-09-06）：AI 大盗直接复用同一决策逻辑，无模式特判——手牌多 3 张（A/B/C 各 1）自然体现在移动/掩护/摸牌选择中；AI 警探不感知模式
