# 弑君者 (Regicide) - 游戏规格文档

## 游戏概述
1~4人合作制卡牌桌游。玩家轮流出牌对城堡中的Boss造成伤害，通过花色技能协同作战，击败或感化全部12个Boss即为胜利。任一玩家无法防御Boss攻击、或酒馆牌库被抽空时则全员失败。

## 卡组构成
- ♥红桃 1~10、J、Q、K（13张）
- ♦方片 1~10、J、Q、K（13张）
- ♠黑桃 1~10、J、Q、K（13张）
- ♣梅花 1~10、J、Q、K（13张）
- 小丑牌：3人局1张、4人局2张（混入酒馆）；1人局2张（单独放置）

## 玩家人数与手牌上限
| 人数 | 手牌上限 | 小丑牌（酒馆） |
|------|---------|---------------|
| 1人  | 8       | 2张（单独放置，非牌库） |
| 2人  | 7       | 0张 |
| 3人  | 6       | 1张 |
| 4人  | 5       | 2张 |

## 卡组初始化

### 城堡（Boss队列）
1. 将4张K（国王）洗混，面朝下放置（最底层，最后出场）
2. 将4张Q（王后）洗混，面朝下放在K上方（中间层）
3. 将4张J（骑士）洗混，面朝下放在Q上方（最顶层，最先出场）
4. Boss出场顺序：J→Q→K，每层内花色随机

### 酒馆（牌库）
- 剩余40张数字牌（1~10，四花色各10张）洗混面朝下
- 3人局加入1张小丑牌、4人局加入2张小丑牌，与数字牌一起洗混

### 发牌
- 每位玩家摸取至手牌上限数量的牌
- 初始手牌中，所有玩家合计必须至少有1张方片（否则重新发牌）

## Boss属性

| Boss | 血量 | 攻击力 |
|------|------|--------|
| J（骑士） | 20 | 10 |
| Q（王后） | 30 | 15 |
| K（国王） | 40 | 20 |

### Boss震慑
- Boss花色决定震慑：该花色卡牌技能无法触发，仅作为数值伤害
- 例：红桃J时，所有红桃牌技能失效
- 震慑效果说明：
  - ♥ 震慑：无法从弃牌堆回收卡牌
  - ♦ 震慑：无法抽取额外卡牌
  - ♠ 震慑：无法降低Boss攻击力
  - ♣ 震慑：受到伤害不会翻倍
- 小丑牌打出后，当前Boss永久失去震慑

## 卡牌技能（酒馆数字牌）

### ♥红桃 - 治愈
洗混弃牌堆，从弃牌堆中随机抽取对应数字张数的牌，放回酒馆最下方。

### ♦方片 - 增援
从打出该牌的玩家开始，按座位顺序轮流抽牌，累计抽牌数量达到对应数字为止。手牌达上限的玩家跳过抽牌。

### ♠黑桃 - 虚弱
按对应数字降低Boss攻击力，最低降到0。

### ♣梅花 - 强力
造成攻击伤害时，伤害 = 卡面数字之和 × 2。

### 🃏 小丑牌
打出后Boss永久失去震慑，跳过本回合伤害/攻击阶段。多人模式指定一名其他玩家执行额外回合（震慑失效）；单人模式可换牌（弃掉所有手牌，摸8张新牌）。

### 技能结算规则
- 单张数字牌：直接结算该花色技能，数值为牌面数字
- 多张数字牌：将所有牌面数字求和，然后对出现的每种花色分别按总和结算技能
  - 例：红桃3 + 方片3 → 总和6 → 结算红桃6效果 + 方片6效果
  - 例：梅花1 + 黑桃9 → 总和10 → 结算梅花10效果 + 黑桃10效果
- 同花色去重：多张同花色牌只触发一次该花色技能（按数字总和）
- Boss震慑的花色，对应技能跳过不结算

## 出牌组合规则（阶段1）
| 组合类型 | 条件 |
|---------|------|
| 单张数字牌 | 1~10 |
| 单张Boss牌 | J/Q/K |
| 对子 | 2张相同数字（1~5） |
| 三条 | 3张相同数字（1~3） |
| 四条 | 4张相同数字（仅1和2） |
| 1+X | 1张1 + 1张数字牌(2~10)或Boss牌(J/Q/K) |
| 1+对子 | 1张1 + 2张相同数字(2~5) |
| 1+三条 | 1张1 + 3张相同数字(2~3) |
| 小丑牌 | 单独打出 |

### 数字1的特殊规则
- 单张1可以单独打出，按普通数字牌方式结算技能和伤害
- 多张1可以组合打出（2张1、3张1、4张1），数字求和后按花色分别结算
- 1可以与其他牌组合：1+单张、1+对子、1+三条
- 同花色去重：例如红桃1 + 红桃9，总和10，只触发一次红桃10效果

## 回合流程

### 阶段1：出牌
当前玩家从手牌中选择合法组合打出。也可以选择跳过出牌（至多连续2人次跳过），跳过后仍需接受Boss攻击。

### 阶段2：技能结算
按上述技能规则结算所有打出卡牌的花色效果。

### 阶段3：造成伤害
- 伤害 = 所有打出牌面数字之和
- 若包含梅花（且未被♣震慑）：伤害 = 数字之和 × 2
- 对当前Boss扣除对应血量

### 阶段4：伤害结算
- **Boss血量 < 0（负数）**：Boss被击杀，进入击杀牌堆
- **Boss血量 = 0（恰好）**：Boss被感化，Boss牌放到酒馆最上方（可被摸取；J=10、Q=15、K=20）
- Boss被击杀或感化后：从城堡翻开下一张Boss，当前玩家重新开始阶段1（跳过阶段5）
- **Boss血量 > 0（有剩余）**：进入阶段5 Boss攻击

### 阶段5：Boss攻击
- Boss攻击力因黑桃虚弱可能已降低
- 当前玩家必须从手牌中打出数值总和 ≥ Boss攻击力的牌作为防御
- 防御牌进入弃牌堆，不触发花色技能
- 无法防御 → 游戏失败（所有玩家本次讨伐失败）
- 防御不受震慑影响
- Boss攻击力为0时自动跳过攻击

## 小丑牌规则

### 多人模式（3~4人）
- 混入酒馆牌库
- 阶段1打出小丑牌后：
  - 当前Boss永久失去震慑
  - 跳过本回合阶段3、4、5
  - 指定一名其他玩家执行一个额外回合（该回合内Boss震慑失效）
  - 额外回合结束后，轮到打出小丑牌玩家的下一家行动

### 单人模式（1人）
- 2张小丑牌单独放在酒馆旁（不混入牌库）
- 点击顶部信息栏的🃏换牌按钮：弃掉所有手牌 → 从酒馆摸8张新牌
- 使用前会弹出确认提示
- 此操作不受震慑影响
- 一局游戏最多使用2次

## 游戏结束条件
- **失败**：任一玩家阶段5无法防御
- **失败**：酒馆牌库被抽空（需要摸牌但无牌可摸时）
- **失败**：轮到某玩家时手牌为空且酒馆无牌可摸
- **胜利**：城堡12个Boss全部被击杀或感化

## 核心算法

### 出牌合法性校验
1. 单张：1~10 或 J/Q/K
2. 对子：2张相同数字，且数字∈{1,2,3,4,5}
3. 三条：3张相同数字，且数字∈{1,2,3}
4. 四条：4张相同数字，且数字∈{1,2}
5. 1+X：1张1 + 1张数字牌(2~10)或Boss牌(J/Q/K)
6. 1+对子：1张1 + 2张相同数字(2~5)
7. 1+三条：1张1 + 3张相同数字(2~3)
8. 小丑牌：单独打出

### 技能结算
1. 计算所有牌面数字之和
2. 收集所有出现的花色（去重）
3. 对每种花色（跳过被震慑的）：
   - ♥：从弃牌堆随机取对应数量的牌放回酒馆底部
   - ♦：从当前玩家开始轮流摸牌直到总数达标
   - ♠：Boss当前攻击力减去对应数值
   - ♣：标记本次伤害为双倍
4. 小丑牌特殊处理

### 伤害计算
- 基础伤害 = 牌面数字之和
- 若包含♣梅花（且未被♣震慑阻挡） → 伤害 × 2

### 防御合法性校验
- 选中的手牌数值总和 ≥ Boss当前攻击力
- 防御牌不触发技能

## 动画效果

### Boss受击
- 快速透明度闪烁 + 水平颤抖（0.3s）

### Boss攻击
- Boss卡缓慢上移12px → 猛地下冲28px + 金色光晕（0.5s）

### Boss退场（击杀/感化）
- 抖动 + 渐隐消失（0.5s）

### 新Boss入场
- 从 scale(0.5) opacity(0.5) 渐显放大到 scale(1) opacity(1)
- 略缩(0.93) → 微弹(1.04) → 归位(1.0)（0.9s）
- 入场完成后屏幕震动（±5~6px，0.6s）

### 血条/攻击条
- 数值变化时宽度过渡动画（0.6s）
