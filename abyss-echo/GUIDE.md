# 《深渊回响》规则导读

## 一、游戏目标

选 1~4 名队员组成探险队，潜入深渊三层，击败最终 Boss **深渊意志**。全队阵亡则失败，可立即重开。

---

## 二、界面导览

### 菜单画面
- 勾选职业复选框选择队员（最多4人），点击 **开始远征** 进入游戏
- **继续上次远征**：读取本地存档继续上一次未完成的征程

### 地图画面
- 圆形节点代表可前往的地点：⚔️战斗 / 🧊精英 / 📖事件 / 🛒商店 / 🛌休息
- 发光节点为可前往节点，灰色为未解锁，暗淡半透明为已访问
- 每层末尾为 Boss 节点

### 战斗画面
- **上区**：敌人列表（显示血量、护甲、状态、意图）
- **中区**：队友列表（显示血量、护甲、状态）
- **下区**：手牌区 + 结束回合按钮
- **战斗日志**：显示最近的行动记录

## 三、职业（4 种）

### 守望者（Warder）— 坦克
- **生命 80** | 颜色：蓝
- **特色机制：守护** — 打出守护牌后，本回合替指定队友承受伤害
- 定位：吸收伤害，保护队友

### 潮汐学者（Scholar）— 法术输出
- **生命 55** | 颜色：紫
- **特色机制：潮汐** — 每打出 3 张法术牌，触发 1 次潮汐爆发（对随机敌人造成 6 点伤害）
- 定位：群体法术伤害，上中毒/虚弱

### 深渊猎手（Hunter）— 物理输出
- **生命 65** | 颜色：绿
- **特色机制：连击** — 本回合每打出 1 张牌，下一张攻击牌伤害 +1
- 定位：多段连击，爆发伤害

### 圣汐医者（Healer）— 治疗辅助
- **生命 60** | 颜色：金
- **特色机制：净化** — 每次移除队友的负面状态（中毒/易伤/虚弱等），获得 1 点能量
- 定位：回血、净化 debuff、加护甲

**初始卡组**：每人 5×打击 + 4×防御 + 1 张职业招牌牌。

## 四、卡牌

### 卡牌属性
- **费用（cost）**：左上角蓝色圆数字，消耗的能量值（0~3）
- **类型**：攻击（红框）/ 技能（蓝框）/ 能力 · Power（紫框，打出后整场生效）
- **目标**：单体敌人 / 全体敌人 / 随机敌人 / 单体队友 / 全队
- **稀有度**：初始（白）/ 普通（common）/ 罕见（uncommon）/ 稀有（rare）
- **升级（+）**：休息点选择升级后，卡牌名称后带 +，效果增强约 30%

### 卡牌效果（战斗中能看到触发）
| 效果 | 说明 |
|------|------|
| **伤害** | 对目标造成伤害 |
| **多段** | 连续造成多次伤害 |
| **护甲** | 给自己或全队加临时护盾（回合结束消失） |
| **治疗** | 恢复生命 |
| **抽牌** | 从牌堆额外抽牌 |
| **能量** | 获得额外能量 |
| **施加状态** | 给敌人上 debuff 或给自己上 buff |
| **消耗** | 打出后移出本局，不进弃牌堆 |

### 牌堆术语
| 名词 | 说明 |
|------|------|
| **抽牌堆（Draw Pile）** | 待抽的牌堆 |
| **弃牌堆（Discard Pile）** | 已打出的牌存放处 |
| **手牌（Hand）** | 手中可打出的牌，上限 10 张 |
| **洗牌** | 抽牌堆为空时，弃牌堆洗入抽牌堆 |

## 五、状态效果（Buff/Debuff）

### 增益（Buff）
| 状态 | 效果 |
|------|------|
| ⚔️ **力量 strength** | 攻击伤害 +X |
| 🛡️ **敏捷 dexterity** | 获得护甲 +X |
| ❤️ **再生 regen** | 回合开始回复 X 生命 |
| 🃏 **潮汐预兆 draw** | 每回合多抽 X 张牌 |
| 🔋 **深渊之眼 energy** | 每回合 +X 能量 |
| 👁️ **守护 guard** | 替队友承受伤害 |

### 减益（Debuff）
| 状态 | 效果 |
|------|------|
| ☠️ **中毒 poison** | 回合开始失去 X 生命，持续整个战斗 |
| 💔 **易伤 vulnerable** | 每层受到伤害 +50%（可叠加） |
| 🌫️ **虚弱 weak** | 每层造成的伤害 -20%（可叠加，最低 -80%） |
| 👻 **恐惧 fear** | 回合开始 X% 概率跳过行动（Boss 用） |
| 😡 **愤怒 rage** | 每受伤 1 次，攻击 +X（Boss 用） |
| 🔮 **诅咒 curse** | 打出攻击牌时损失 X 生命 |

## 六、敌人

### 意图系统
敌人头顶显示本回合即将采取的行动，颜色表示类型：
- **红色** 攻击（含多重/全体攻击）
- **橙色** 全体攻击
- **蓝色** 护盾
- **绿色** 减益（中毒等）
- **紫色** 召唤
- **黄色** 治疗/增益

> **难度须知**：敌人血量会随队伍人数增长（普通/精英 4 人队约是单人队的 2 倍，Boss 约 1.5 倍），攻击伤害会随层数提升（第 3 层约 1.6 倍）。人越多火力越足，但每个敌人也越难缠；越深的层，伤害越疼。

### 普通敌人（前 2 层常见）
| 敌人 | 特点 |
|------|------|
| **深潜者 deep_one** | 攻防均衡，还会上虚弱 |
| **触手怪 tentacle** | 纯攻击，伤害不高但稳定 |
| **深渊爬虫 crawler** | 低血量，附带中毒 |
| **潮汐祭司 priest** | 能加力量和持续攻击 |
| **深渊守卫 guard** | 先叠甲后攻击 |
| **腐蚀水母 jelly** | 攻击带中毒 |
| **深渊狂信徒 fanatic** | 高攻击 |
| **深渊吞噬者 devourer** | 高攻击+治疗 |

### 精英敌人（紫色边框）
| 敌人 | 特点 |
|------|------|
| **深渊憎恶 abomination** | 会召唤触手怪 |
| **潮汐领主 tide_lord** | 全体攻击+叠力量 |

精英战斗胜利额外掉落一件遗物。

### Boss
| Boss | 层 | 特点 |
|------|----|------|
| **深渊巨目 The Great Eye** | 1 | 攻击→召唤→攻击，考验单体清怪能力 |
| **潮汐主母 Tide Matron** | 2 | 全体攻击+中毒+召唤，考验群体防御 |
| **深渊意志 The Abyssal Will** | 3 | **三阶段**：>66%HP 攻击+护甲 → 33%-66% 全体攻击+恐惧 → <33% 狂暴双动 |

## 七、遗物

遗物是整局持续生效的被动效果，从精英战斗、商店、事件中获得：

| 遗物 | 效果 |
|------|------|
| **深渊护符** | 战斗开始全队 +8 护甲 |
| **潮汐罗盘** | 每回合多抽 1 张牌 |
| **珊瑚之心** | 战斗开始全队治疗 5 点 |
| **深渊之眼** | 每回合 +1 能量 |
| **墨鱼囊** | 回合结束全队 +4 护甲 |
| **珍珠项链** | 获得金币 +20% |
| **深潜者之鳞** | 受到伤害 -2 |
| **潮汐圣杯** | 治疗量 +5 |
| **深渊信标** | 精英战斗奖励多 1 张卡牌选择 |
| **远古石板** | 休息点可同时选两个选项 |

## 八、地图节点

每层有 10 个节点，排成 4 行（2/3/3/2 个节点），层末是 Boss。

| 节点类型 | 说明 |
|---------|------|
| **战斗** | 普通敌人，胜利后得金币+三选一卡牌 |
| **精英** | 强力敌人，胜利额外得遗物 |
| **事件** | 随机事件，多种选项 |
| **商店** | 购买卡牌/遗物/治疗/删卡 |
| **休息** | 恢复 30% 生命 或 升级一张卡牌 |
| **Boss** | 每层最终挑战 |

---

## 九、小贴士

1. **护甲不继承**：每回合结束护甲清零，不要留着护甲不用
2. **全队共享回合**：所有队员可以在任意顺序出牌，打完再结束回合
3. **手牌上限 10 张**：超出会丢弃，注意控制
4. **治疗要给对人**：治疗牌需要选择目标队友
5. **每层 Boss 前有休息点**：尽量用来恢复或升级
6. **金币很重要**：商店里买牌/删卡能显著提升牌组质量
7. **死亡不可逆**：队员死亡后不再参与战斗，全员死亡即失败
