# 深渊回响 (Abyss Echo) — 规则文档

## 游戏概述
深海克苏鲁主题的合作肉鸽卡牌构筑游戏（参考月圆之夜 / 杀戮尖塔 / Across the Obelisk）。
纯静态 HTML 单机版：1 名玩家操控 1-4 人小队，潜入深渊三层，击败最终 Boss【深渊意志】。
一次完整的深渊之旅称为一局（Run）；小队全灭即失败，可立即重开。

## 背景故事
- **深渊先民**：远古时代曾有一个辉煌的文明，他们在海沟最深处筑起宏伟的城邦，将知识、财富与力量封存于深渊核心，随后沉入永夜。
- **核心**：深渊先民遗留的造物，是深渊的力量之源。它被沉睡于最底层的【深渊意志】所侵蚀，腐化自核心向外蔓延，孕育出深潜者、触手怪等扭曲的造物。
- **烛火结社**：玩家扮演的探索者组织。执灯人、学者、猎手与医者手持微弱的烛火，沿先民的遗迹一路下潜，夺回核心、净化腐化。
- **深渊意志**：沉睡于最深处的一切的意志本身（最终 Boss）。它没有躯体，只有意志——它会召唤、腐蚀、吞噬所有接近核心的生命。

## 基本流程
1. 选择人数（1-4 名队员）与各队员职业，开始新局。
2. 生成 3 层地图，每层由多行节点组成（MAP_ROWS = [2, 3, 3, 2]，全图 10 个节点）。
3. 在地图上逐节点前进，节点类型：
   - **战斗**（普通遭遇）/ **精英** / **事件** / **商店** / **休息**
4. 每层末尾遭遇层 Boss：
   - 第 1 层：深渊巨目
   - 第 2 层：潮汐主母
   - 第 3 层：深渊意志（三阶段）
5. 击败第 3 层 Boss 即通关。
6. 小队全灭（所有队员生命 ≤ 0）→ 失败，本局结束，可重新开局；永久解锁与统计保留。

## 战斗规则
- **回合制**：全队共享一个回合。回合内所有存活玩家**以任意顺序**轮流打出卡牌，无固定行动次序。
- **能量**：每人独立能量，基础 3 点/回合；能量卡与【深渊之眼】遗物/状态可增加。
- **抽牌**：每人每回合抽 5 张（受【潮汐预兆】状态与【潮汐罗盘】遗物加成）。
- **手牌上限**：10 张，超出的部分丢弃。
- **护甲**：护甲吸收伤害，**回合结束清除**，不跨回合保留。
- **结束回合**：所有玩家都打完牌后点【结束回合】，敌人按意图行动，然后进入下一回合。
- **死亡**：队员生命归 0 即死亡，不再参与出牌；全队死亡则战斗失败。
- **目标**：攻击牌需选择目标敌人，治疗/增益牌选择目标队友（target 决定可选目标）。

## 卡牌系统
### 基础属性
- **费用**：0-3 能量（cost）
- **类型**：攻击（attack）/ 技能（skill）/ 能力（power）
- **目标**：enemy（单体敌人）/ ally（单体队友）/ allEnemies（全体敌人）/ allParty（全队）/ self（自身）/ randomEnemy（随机敌人）
- **稀有度**：初始（starter）/ 普通（common）/ 罕见（uncommon）/ 稀有（rare）；奖励卡稀有度权重 common 60 / uncommon 30 / rare 10
- **升级（+）**：upgEffects 覆盖原效果；未显式定义升级时，按统一规则自动增强（约 +30%）
- **消耗（exhaust）**：打出后移出本局，不进入弃牌堆（字段或 exhaust 修饰符）
- 全卡池 68 张：4 职业各 14 张 + 中立 12 张

## 敌人系统
### 意图循环
- 普通敌人按**循环模式**行动：intents 数组，回合数 round % length 取意图（如深潜者 4 回合一个循环）。
- 支持 `weighted:true` 加权随机模式（按 w 权重选择意图）。
- 意图类型：`attack` 攻击 / `multi` 多段攻击 / `allAttack` 全体攻击 / `block` 格挡 / `buff` 增益 / `debuff` 单体减益 / `allDebuff` 全体减益 / `summon` 召唤 / `heal` 治疗。
- 敌人 HP 与伤害随层数缩放：实际值 = 基础值 × FLOOR_SCALE（层 1/2/3 = 1 / 1.3 / 1.6）。
- **队伍人数缩放**：敌人血量再按队伍人数缩放——普通/精英 ×[1, 1.3, 1.6, 2]，Boss ×[1, 1.15, 1.3, 1.5]（按 1/2/3/4 人取值，先乘层数再乘人数）。
- **攻击缩放**：敌人的攻击类意图（attack / multi / allAttack）伤害按层数缩放：层 1/2/3 = ×1 / ×1.3 / ×1.6。仅乘基础值，力量/愤怒/易伤等加成在缩放后结算；block / debuff / buff / heal / summon 与中毒等减益层数不缩放。

## 地图与层数曲线
- 地图按行生成：MAP_ROWS = [2, 3, 3, 2]，共 10 个节点，分为 3 层，层末为层 Boss。
- 节点类型权重（NODE_WEIGHTS）：战斗 40 / 事件 30 / 商店 15 / 休息 15。
- 层数曲线（FLOOR_SCALE）：层 1 = 1.0，层 2 = 1.3，层 3 = 1.6，作用于敌人强度（HP/伤害）。
- 敌人血量随队伍人数缩放（普通/精英 ×[1,1.3,1.6,2]，Boss ×[1,1.15,1.3,1.5]），敌人攻击意图按层数 ×1/×1.3/×1.6 缩放。
- 敌人与遭遇随层递进（见敌人系统），精英与 Boss 逐层出现。

## 永久解锁
- **硬核模式**：首次通关后解锁，面向高难度挑战（更高敌人强度）。
- **胜利统计**：记录通关次数、胜场等局外统计，保存在本地（localStorage），跨局保留。
- 死亡重开不影响已获得的永久解锁与统计。
