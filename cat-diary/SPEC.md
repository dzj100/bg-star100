# 捉虫猫日记 - 技术规格文档

## 概述
2人本地热座对战桌游助手。每位玩家操控一只猫（蓝猫/橙猫），在3×3棋盘上移动并翻开格子，率先使场上出现6只目标昆虫即获胜。

## 游戏组件

### 9张板块（洗混后3×3排列）
| # | 正面 | 背面 |
|---|------|------|
| 1 | 草地 | 2蝴蝶 |
| 2 | 草地 | 2瓢虫 |
| 3 | 草地 | 2蝴蝶 + 1瓢虫 |
| 4 | 草地 | 2瓢虫 + 1蝴蝶 |
| 5 | 草地 | 1蝴蝶 + 1瓢虫 |
| 6 | 石头 | 1蝴蝶 |
| 7 | 石头 | 1瓢虫 |
| 8 | 石头 | 沼泽 |
| 9 | 石头 | 沼泽 |

### 玩家
- **蓝猫**（先手）：目标收集 🐞瓢虫，6只以上获胜
- **橙猫**（后手）：目标收集 🦋蝴蝶，6只以上获胜
- 每人初始获得 **3个捕虫网标记**

### 初始设置
- 9张板块洗混后放入3×3网格（位置0-8，从左到右从上到下）
- 随机对角出生：(0,8) 或 (2,6)
- 双方起始格不翻开

## 行动系统

每位玩家有独立的行动周期，每个周期内3种行动各限用1次：
1. **走1步** → 翻转到达格
2. **走2步** → 翻转途径格（第1步到达的中间格子）
3. **走3步** → 翻转出发格（移动前所在的位置）

当一名玩家的3种行动全部用完后，该玩家的行动次数重置。

### 交互流程
1. 玩家点击选择一个未使用的行动类型
2. 当前可到达的相邻格高亮提示，玩家依次点击格子构建路径
3. 每次点击后可选范围更新为新位置的相邻格（不可回头）
4. 路径长度达到行动要求后，「确认」按钮可用
5. 过程中可「撤销」上一步或「取消」重新选择行动
6. 确认后执行移动 + 翻转逻辑

### 移动规则
- 仅可走相邻格（上下左右），不可斜走
- 可以拐弯，但同一次移动中不能重复经过同一格
- 不能停在已翻开的沼泽上（可以作为途经点经过）
- 未翻开的格子无论背面是什么都可以行走

### 翻转规则
- 未翻开的格子 → 带3D动画翻开，显示背面内容
- 已翻开的格子（无捕虫网、非沼泽）→ 弹出选择弹窗：翻回去 / 放捕虫网 / 不操作
- 放过捕虫网的格子 → 不可再翻转
- 沼泽格 → 一旦翻开永久保持翻开状态
- 草地和石头正面的格子都可以被翻转

### 捕虫网
- 放在已翻开的格子上，永久锁定该格
- 每人全场共3个捕虫网
- 锁定格显示对应玩家颜色的网罩覆盖层

## 胜利条件
每回合结束时检查：
- 场上翻开的 🐞瓢虫 ≥ 6 → 蓝猫获胜
- 场上翻开的 🦋蝴蝶 ≥ 6 → 橙猫获胜
- 统计全场所有翻开的昆虫，不区分是谁翻开的

## 数据结构

```js
{
  phase: 'landing' | 'playing' | 'game-over',
  tiles: [
    { id, frontType:'grass'|'stone', back:{butterfly:n,ladybug:n}|'swamp', flipped:bool, net:null|'blue'|'orange' }
  ],
  players: [
    { id:'blue', name:'蓝猫', pos:int, nets:3, actionsUsed:[false,false,false] },
    { id:'orange', name:'橙猫', pos:int, nets:3, actionsUsed:[false,false,false] }
  ],
  currentPlayer: 0,   // players数组索引
  winner: null,        // 'blue' | 'orange' | null
}
```

瞬态UI状态（不存入localStorage）：
```js
{
  selectedAction: null,  // 0|1|2 当前选择的行动类型
  path: [],              // 路径规划中的格子索引数组
  pendingFlip: null,     // 等待选择操作的格子索引
}
```

## 界面布局

### 首页
- 标题「捉虫猫日记」
- 副标题「2人对战桌游助手」
- 右上角「📖 规则」按钮
- 「开始游戏」按钮
- 底部 @imStar100 落款

### 游戏页
- **吸顶抬头栏**（fixed定位，全屏宽度）：游戏名称 + 「↺ 重置」按钮 + 「📖 规则」按钮
- **状态栏**：当前玩家指示器 + 目标昆虫提示 + 全场昆虫计数
- **信息提示区**：当前操作引导文字
- **3×3棋盘**：带3D翻转动画的格子网格
  - 未翻开：草地(绿)/石头(灰)外观
  - 已翻开：奶白底显示昆虫emoji
  - 玩家猫咪标记（36px圆形头像）
  - 捕虫网覆盖层（72px emoji，50%透明度）
- **底部操作区**：
  - 行动中：3个行动按钮（走1步/走2步/走3步）
  - 路径规划中：撤销/取消/确认按钮
  - 游戏结束后：「再来一局」按钮

### 弹窗
- **翻转选择弹窗**：翻回去 / 放捕虫网 / 不操作
- **规则弹窗**：完整游戏规则，可滚动查阅
- **重开确认弹窗**：二次确认后清除存档回到首页
- **胜利弹窗**：显示获胜方，点击遮罩可关闭回顾棋盘

### 格子动画
- CSS 3D transform翻转（rotateY 180deg），perspective 600px
- 过渡时长 ~0.5s
- 通过requestAnimationFrame双帧延迟触发动画
