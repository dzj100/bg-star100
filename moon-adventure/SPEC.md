# 月面探险 (Moon Adventure) - 全流程助手

## 游戏概述
Oink Games 出品的2-5人合作桌游。玩家扮演宇航员，在氧气耗尽前合作回收月面物资并安全返回基地。

## 角色 ×5
| 角色 | 能力 |
|------|------|
| 工程师 | 每回合开始可让机器人移动0-2步（仅工程师在场时机器人才参与游戏） |
| 搬运工 | 拥有6个存储槽（其他角色5个） |
| 发明家 | 每回合可用1AP放置加速标记（标准2AP），且可选择停留在加速标记上 |
| 气氛组 | 掷出相同数字时，额外获得3AP |
| 老兵 | 资源回收仅需2AP（标准3AP） |

## 扩展角色 ×5（设置页勾选「使用扩展角色」后加入随机池）
| 角色 | 能力 |
|------|------|
| 技术员 | 每回合1次，行动前可重掷全部骰子 |
| 鉴定师 | 每回合1次，消耗1AP翻开自己1张物资牌查看完好/损坏 |
| 后勤 | 每回合首次共享物资不消耗AP |
| 建造师 | 每回合首次建立OGS仅需1AP |
| 先锋 | 回合开始时身处活跃OGS上额外获得2AP |

- 勾选后角色从10名中随机分配，一人一个不重复

## 卡牌组成
### 氧气卡 ×15
- 2氧气卡 ×10（打出后掷2个骰子）
- 3氧气卡 ×5（打出后掷3个骰子）
- 骰子面为1~3

### 磁暴卡 ×4
- 混入氧气抽牌堆
- 抽到时摧毁当前OGS芯片（红色→黑色）
- 洗回时从备用磁暴中逐张加入抽牌堆（整局最多4张）

## 初始分配
- **氧气卡**: 每人固定 2张2氧气 + 1张3氧气
- **角色卡**: 随机分配
- **抽牌堆**: 空（首次OGS补给时触发洗回）
- **弃牌堆**: 剩余氧气卡（2人9张，3人6张，4人3张，5人0张）
- **备用磁暴**: 4张（每次洗回时加入1张到抽牌堆，所有人数组局均为4张）
- 5人局开局时弃牌堆为空（无氧气卡，磁暴备用仍为4张）

## 存储槽
- 普通角色5槽，搬运工6槽
- 氧气卡 + 物资板块 共用槽位
- 槽位满时无法拾取物资或抽取氧气
- 物资在背包中按拾取区域显示对应形状（区域1三角/区域2菱形/区域3五边形）

## 物资板块 ×21
| 区域 | 形状 | 背面数字 | 完好 | 损坏 | 合计 |
|------|------|---------|------|------|------|
| 区域1 | 三角形 | 3 | 3 | 4 | 7 |
| 区域2 | 四边形 | 4 | 4 | 3 | 7 |
| 区域3 | 五边形 | 5 | 5 | 2 | 7 |

- 所有物资始终只显示背面（含玩家背包中的）
- 仅在游戏结束结算时翻开正面

## 月面场地
- S形蛇形路径，3区域各7个板块
- 板块之间有"间隙"位置（可放置OGS芯片或丢弃的物资）
- 基地在起点（所有玩家初始在基地）
- 月球车在区域3末尾（仅1辆，先到先得）
- 机器人在基地（仅工程师在场时参与）
- OGS芯片阻挡该方向的物资回收（无法穿透OGS拾取更远板块的物资）

## 回合流程

### 1. 失败条件检查 / 紧急救援
回合开始时，若玩家无氧气卡：
- 若序列相邻位置（含板块、OGS芯片等，不含基地）有持有氧气卡的玩家 → 触发**紧急救援**（双向转移，救援双方可互相转移氧气/物资，不消耗发起时的AP；救援后被救玩家下一回合掷骰时-1AP）
- 若无可救援的相邻玩家 → 全员失败

### 2. 打出氧气卡 → 掷骰子
- 选择一张氧气卡打出
- 获得对应数量的骰子（2或3个）
- 骰子点数之和 = AP

### 3. 支配AP
| 行动 | AP消耗 | 说明 |
|------|--------|------|
| 移动 | 1AP起 | 点【移动】后地图高亮可达格并显示AP成本，点击支付AP直达；越过有玩家/加速标记/机器人的格子（发明家可停在加速标记上） |
| 物资回收 | 3AP (老兵2AP) | 拾取相邻板块物资（面朝下进背包），原位放X标记；OGS芯片阻挡该方向 |
| 放置加速标记 | 2AP (发明家1AP) | 放在前方或后方的板块/损毁OGS芯片上，不能放在正常OGS芯片上 |
| 建立OGS芯片 | 3AP | 放在当前板块与相邻板块的间隙中（最多5个） |
| 共享物资 | 1AP | 与序列相邻位置的玩家交换氧气/物资（基地中不可共享） |
| 物资丢弃 | 1AP | 丢弃到相邻间隙中（板块或损毁OGS位置均可，作为新元素插入路径） |

### 4. OGS补给（可选）
- 必须在正常运转的OGS芯片上
- 若剩余AP > 0，需确认后AP自动清零再开始补给；AP = 0 时直接开始
- 逐张抽取，可选择继续或停止
- 抽牌堆空但弃牌堆有氧时，可继续抽取（自动触发洗回）
- 抽到磁暴 → OGS损坏（红→黑），磁暴进弃牌堆
- 洗回逻辑：弃牌堆全部清空（氧气+磁暴一起洗回抽牌堆），再从备用磁暴加入1张

### 5. 结束回合
- 返回基地的玩家不再行动，跳过后续回合

## 月球车规则
- 到达月球车时清空剩余AP
- 驾驶后1AP移动2步（前进或后退均可，每次固定2步）
- 人车绑定直到游戏结束，不再下车
- 不可拾取物资、放置加速标记、建立OGS
- 可以共享物资、丢弃物资、OGS补给
- 仅1辆，搭载1人

## 加速标记规则
- 可放置在前方或后方的板块/损毁OGS芯片上（不能放在正常OGS芯片上）
- 其他玩家经过时免费跳过（不消耗步数）
- 有加速标记的板块物资不可被回收
- 发明家可选择停留在加速标记上
- 移动时自动跳过加速标记

## 物资丢弃规则
- 丢弃到相邻间隙中（前/后方向），作为新的路径元素插入，路径长度+1
- 丢弃的物资在地图上显示为对应区域形状

## 紧急救援规则
- 回合开始时无氧气且序列相邻位置有持有氧气的玩家时触发
- 不消耗发起时的AP；救援后被救玩家下一回合掷骰时-1AP
- 双向转移（救援双方可互相转移氧气/物资，受存储槽限制）
- 可取消：点击遮罩层取消本次救援，已转移物资回滚到原玩家存储槽，回到等待救援状态
- 救援后仍无氧气 → 全员失败

## 基地规则
- 基地中的玩家之间不可共享物资
- 基地旁无间隙，不可建立OGS芯片
- 从基地出发时，跳过有玩家/机器人/加速标记的位置

## 获胜条件
| 人数 | 完好物资 |
|------|---------|
| 2人 | 5+ |
| 3人 | 7+ |
| 4人 | 8+ |
| 5人 | 9+ |

## 失败条件
1. 回合开始时无氧气且无法通过紧急救援获得 → 全员失败
2. 全员返回基地后完好物资不足 → 全员失败
