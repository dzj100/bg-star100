游戏规则

🎯 游戏目标

共进行5轮探险，累计获得最多宝石和神器的玩家获胜。

💎 宝石卡（15张）

  • 翻开后按当前深入中玩家数均分
  • 除不尽的余数留在探险路径上

⚖️ 神器卡（5张：5、7、8、10、12）

  • 每轮开始时从剩余神器中随机加入1张到牌堆
  • 翻开后留在路径上，不自动分配
  • 仅1人撤退时，该玩家获得路径上所有神器
  • 多人同时撤退时，神器留在路径上不处理

💥 灾难卡（5类×3张）

  • 蜘蛛🕷️、毒蛇🐍、火焰🔥、落石🪨、僵尸🧟
  • 同类灾难出现第2张时 → 探险失败
  • 失败后：所有深入玩家本轮收益清零
  • 移除1张该灾难卡 + 路径上未领取的神器

🏕️ 返回营地

  • 每次翻牌后可选择撤退的玩家
  • 撤退玩家均分路径上的余数宝石
  • 本轮已分配的宝石 + 余数 + 神器一起转入背包

🔄 轮次结束

  • 所有人撤退或探险失败后本轮结束
  • 未领取的神器从游戏中移除
  • 路径上其他卡牌回收至牌堆并洗混
  • 被移除的灾难卡和神器展示在页面上

📦 牌堆构成

宝石15张 + 灾难15张 = 30张，每轮再随机加入1张神器
