# Scoundrel（无赖勇者）单人卡牌闯关 — 开发 SPEC

纯静态 HTML5 单人卡牌游戏，中文界面，移动端优先（PC 可用）。
目录：`scoundrel/`（index.html、style.css、game.js、render.js、test.js、SPEC.md）。

## 1. 牌组构成（共 44 张）

从 54 张牌（含大小王）中移除：红桃 JQKA、方片 JQKA、大小王（共 10 张）。

| 花色 | 点数 | 数量 | 类型 |
|---|---|---|---|
| 红桃 | 2~10 | 9 | 血瓶 |
| 方片 | 2~10 | 9 | 装备（武器） |
| 黑桃 | 2~A | 13 | 怪物 |
| 梅花 | 2~A | 13 | 怪物 |

点数映射：2~K = 2~13，A = 14。

## 2. 核心数值

- 初始血量 20，上限 20（回复不可超过上限，超出浪费）。
- 牌堆初始 44 张，Fisher-Yates 洗牌。
- 房间 = 当前展示的牌（≤4 张）；已消耗的牌离开游戏，无弃牌堆。

## 3. 房间流程

1. 开局：从牌堆顶翻 4 张作为房间。
2. 玩家以任意顺序处理房间中的牌（每张牌只能处理一次）：
   - **红桃（血瓶）**：点击喝下，回复点数血量（上限 20）；每个房间只有第一瓶生效，第二瓶及之后回复 0（仍消耗牌）。
   - **方片（装备）**：点击装备，替换并丢弃当前武器；新武器默认启用，无对决历史。
   - **黑桃/梅花（怪物）**：点击对决，结算见 §4，结算后该牌消耗。
3. 房间只剩 1 张牌时，自动进入下一房间：保留这 1 张，从牌堆顶补牌直到 4 张（牌堆不足则补剩余；牌堆为空则不补）。
4. 每次进入新房间（含开局、补牌形成的新房间）都可在行动前选择踢门（见 §5），受连续使用限制。

## 4. 对决结算

- **无装备**（未装备或武器被收起）：损失血量 = 怪物点数。
- **有装备且启用**：
  - 装备点数 >= 怪物点数：无损击杀。
  - 装备点数 < 怪物点数：损失血量 = 怪物点数 − 装备点数（部分减伤）。
- **递减限制**：当前武器记录"上次用该武器对决的怪物点数"（跨房间保留）。新装备的武器没有记录，首次对决无限制；此后用该武器对决的怪物必须**严格小于**上次记录。违反时武器不生效，本次按空手结算（损失全额），武器保留且记录不变。
- 空手对决不影响武器记录。
- 只有装备新方片（替换武器）时才清空记录；反选收起再勾选启用**不**清空记录，递减限制继续生效。

## 5. 装备与踢门

- 装备栏只持有**一把**武器，可勾选启用 / 反选收起（收起时对决按空手结算）。勾选状态随时可切换，不消耗行动。
- **踢门**：进入新房间时（房间恰好 4 张）可用。效果：将当前房间 4 张牌洗混后放入牌堆底部，再从牌堆顶翻 4 张（不足则翻剩余）。
- 限制：
  - 不能连续使用：踢门后，紧接着的下一个房间禁止踢门，再下一个恢复。
  - 房间牌数 ≠ 4 时不可用。
  - 牌堆为空时按钮禁用（操作无意义）。

## 6. 胜负判定

- 每次行动结算后检查：
  - 血量 <= 0 → **失败**（立即结束）。
  - 牌堆清空 且 当前房间牌全部消耗 → **胜利**。

## 7. UI / 交互

- 布局：顶部血量条（20/20），中部房间牌区（4 张，可点击），底部装备栏 + 踢门按钮 + 牌堆剩余张数。
- 装备栏：武器牌旁展示该武器的对决记录（上次对决的怪物点数；新武器显示"未对决"）。反选收起时记录仍保留展示，勾选启用后递减限制继续生效。
- 点击牌即时行动；伤害/回复飘字；武器失效（递减不满足）时点击怪物按空手结算并给出提示。
- 结算画面：胜利 / 失败 + 重新开始。
- localStorage 自动存档（进行中的局：血量、牌堆顺序、房间、武器与记录、血瓶计数、踢门禁令），刷新可继续；新游戏需确认覆盖。
- 不提供撤销（防止利用已翻开的牌堆信息）。
- 轻量动画：翻牌、飘字、掉血红闪；WebAudio 合成音效：对决、喝药、踢门、胜利、失败。

## 8. 技术方案

- 规则引擎纯函数化（不碰 DOM）：`buildDeck / newGame / act(cardId) / toggleWeapon() / kick() / state 快照`，所有规则集中在 `game.js`。
- 渲染层 `render.js` 监听 state 重绘（与 abyss-echo 同风格）。
- `test.js`：node 无头测试，覆盖牌组构成（44 张、点数映射）、补牌逻辑、对决结算矩阵（空手/满挡/部分减伤/递减违反）、踢门限制（连续禁令、牌数条件）、血瓶只生效一瓶、胜负判定。
- 完成 UI 后用 Playwright 截图验收（沿用仓库 `.shots` 做法）。

## 10. 默认设定（有异议请指出）

- 游戏名"Scoundrel（无赖勇者）"，可改名。
- 开局第一间房即可踢门（"进入新房间"包含开局）。
- 补牌形成的新房间（4 张）同样可踢门，受连续限制。
- 牌堆为空时禁用踢门（规则未禁止但无意义）。
- 武器收起状态下点击新方片 = 直接替换旧武器，新武器启用。
