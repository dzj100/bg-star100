# 牛头王 UI / 美术待办

> 本轮已处理并验证：
> - 出牌区空槽引导：每行按剩余容量补 4 格以内的虚线空槽（`.row-track .row-slot`），卡牌与空槽共用 `--row-cw`。
> - 移动端玩家条：芯片定宽 98px（原先被状态文字撑到约 151px），左右两侧按滚动位置渐隐，提示可横滑。
>
> 下面按优先级列出其余待评估项，动手前建议先确认视觉方向。

## P1 · 可读性

### 1. 牛头计数图标容易读成「¥」

- 现状：`renderRows()` 里 `.row-bulls` 用 16px 的 `#bull-head` 加数字，行头小尺寸下双角和鼻梁的组合更像货币符号。
- 方向：换成更完整的牛头剪影（保留耳朵与口鼻留白），数字前加 `×`；或直接用「牛×N」文字。
- 涉及：`render.js` 的 `renderRows()`、`.row-bulls` 样式、`index.html` 中的 `#bull-head` symbol。
- 验收：375px / 320px 截图里能一眼读出「本行牛头总数」。

### 2. 小屏次要文字偏小

- 现状：`.chip-status` 8.5px、`.reveal-slot .reveal-name` 7.5px，320px 下接近不可读。
- 方向：状态文字提到 9px 左右，亮牌名提到 8.5px；或把「已锁定 / 思考中 / 选行中」改成色块 + 短词。
- 注意：不能因此增加玩家条高度或挤压四行桌面。
- 涉及：`style.css` 的移动端媒体查询、`.chip-status`、`.reveal-name`。

### 3. 小屏 A–D 行头过于抢眼

- 现状：`<=359px` 时行头仍占 36px 宽、17px 字，而牌宽只有约 21px，视觉重量倒挂。
- 方向：窄屏把行头压到 30–32px，字母 14–15px，牛头数 8px；或改成细长色条 + 字母。
- 涉及：`@media (max-width: 359px)` 中的 `.row-head` / `.row-title` / `.row-bulls`。

## P2 · 视觉层级

### 4. 整块红色区域偏多

- 现状：顶栏、主按钮、侧栏标题（`.side-block > header`）都是大面积红底，红色失去「主操作」指向性。
- 方向：日志 / 计分侧栏标题改成米白底 + 红字 + 红色细边；红色只留给「开始游戏」「锁定出牌」等主操作。
- 涉及：`.side-block > header`、`.log-panel`、`.latest-log` 及对应弹窗标题。

### 5. 顶栏进度点的层级

- 现状：10 个圆点里已完成 / 当前 / 未到的区分在红底上不够明显，容易和标题抢注意力。
- 方向：当前墩改为更大的空心环，已完成用实心点；或直接显示「3 / 10」文本，弱化圆点。
- 涉及：`renderTopbar()` 与 `.dot` / `.dot.done` / `.dot.current`。

### 6. 首页存档状态的优先级

- 现状：有存档时「继续上局」是幽灵按钮，排在红色「开始游戏」下面。
- 方向：有存档时把「继续上局」升为主按钮，原按钮改成「新开一局」；可附一行「第 3 / 10 墩 · 6 人」摘要。
- 涉及：`renderMenu()`、`#btnStart` / `#btnContinue`、`.menu-actions`。

## P3 · 终局表现

### 7. 终局冠军与本人行强调不足

- 现状：结算页只有名次数字变红，缺少「冠军」符号；玩家自己的那一行也不够醒目。
- 方向：冠军行加皇冠 / 「牛王」徽标；本人行用米金底或左侧色条强调，并保持和现有 B 主题一致。
- 涉及：`renderOver()` 的排名输出、`.rank-row.is-winner`、`.rank-row.is-me`。
